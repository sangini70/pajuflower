## 1. 전체 Information Architecture

사이트의 기본 구조는 교회 내부 조직이나 행사 목록이 아니라, 교회와 기독교를 처음 접하는 사람의 질문 순서를 중심으로 설계되어 있다.

```text
홈
├─ 기독교란?
│  └─ 하나님 → 인간 → 죄 → 예수 그리스도 → 믿음과 새로운 삶
├─ 예수님
│  └─ 삶과 가르침 → 십자가 → 부활 → 직접 읽기
├─ 교회 방문
│  └─ 방문 전 → 걱정 해소 → 예배 당일 흐름 → 건강한 교회 점검 → 방문 후
├─ 자주 묻는 질문
│  └─ 기독교 / 성경 / 교회 / 생활 질문
├─ 익명 질문
│  └─ 이름·이메일 없이 질문 등록 및 답변 확인
├─ 더 알아보기
│  └─ 성경 읽기 → 짧은 기도 → 교회 방문 → 사람과 대화 → 질문 기록
└─ 추가 진입
   └─ 복음 설명 페이지, 사이트 소개, 언어 전환
```

### IA의 핵심 특징

1. **기관 중심이 아니라 질문 중심이다.**  
   교회 소개를 첫 번째 정보로 밀어 넣지 않고, 방문자가 실제로 궁금해하는 질문을 최상위 메뉴로 사용한다.

2. **개념 이해에서 행동으로 이동한다.**  
   `기독교란?`과 `예수님`에서 의미를 설명한 뒤 `교회 방문`과 `더 알아보기`로 다음 행동을 연결한다.

3. **페이지 간 순차 흐름이 있다.**  
   일부 페이지는 이전 내용과 다음 내용을 함께 제공해 독자가 길을 잃지 않게 한다.

4. **FAQ와 익명 질문을 별도 진입점으로 둔다.**  
   정해진 설명을 읽는 것만으로 해결되지 않는 불안을 질문으로 전환할 통로를 제공한다.

5. **홈페이지 안에 짧은 안내와 깊은 페이지를 함께 둔다.**  
   홈에서는 카드와 요약으로 선택하게 하고, 내부 페이지에서 충분한 설명을 제공한다.

## 2. 첫 방문자를 위한 콘텐츠 흐름

관찰된 흐름은 다음과 같다.

```text
환영
  ↓
지금 궁금한 질문 선택
  ↓
기독교의 기본 구조 이해
  ↓
예수님의 인물과 십자가·부활 이해
  ↓
예배와 교회가 실제로 무엇을 하는지 이해
  ↓
첫 방문의 불안 해소
  ↓
FAQ·익명 질문으로 남은 의문 처리
  ↓
성경 읽기·기도·방문·대화 중 작은 다음 행동 선택
```

홈 Hero는 “처음이라도 괜찮다”는 정서적 허용과 “질문에서 시작한다”는 행동 지침을 함께 준다. 바로 등록하거나 결단하라는 대신, 여러 진입 카드 중 현재 가장 궁금한 항목을 고르게 한다.

### 파주꽃동산교회 적용 원리

파주꽃동산교회 홈페이지에서도 기존 성도용 정보와 비신자용 진입 흐름을 한 화면에서 섞어 복잡하게 만들기보다, 첫 방문자가 선택할 수 있는 별도 진입을 제공할 수 있다.

권장 흐름:

```text
환대의 Hero
  ↓
처음 오셨나요?
  ├─ 교회는 어떤 곳인가요?
  ├─ 예수님과 말씀을 알고 싶어요
  ├─ 예배는 어떻게 드리나요?
  └─ 처음 방문을 준비하고 싶어요
  ↓
현재 예배 안내
  ↓
질문·문의·설교 보기
```

다만 파주꽃동산교회의 핵심은 `한걸음` 사이트처럼 기독교 입문 사이트가 되는 것이 아니다. 교회와 목회와 실제 공동체가 중심이며, 질문형 안내는 교회로 들어오는 부담을 낮추는 보조 흐름으로 사용해야 한다.

## 3. 기독교를 모르는 사람에게 설명하는 방식

### 관찰된 설명 원리

- 내부 용어를 먼저 정의하지 않고 질문형 제목을 사용한다.
- 기독교를 단순한 도덕 규칙이나 종교 행사로 축소하지 않는다고 먼저 선을 긋는다.
- 하나님, 인간, 죄, 예수 그리스도, 믿음과 새로운 삶을 인과관계가 있는 이야기로 묶는다.
- 교단에 따라 세부 표현이 다를 수 있음을 밝힌다.
- 사실에 가까운 역사 설명과 기독교의 신앙고백을 구분한다.
- 기독교인의 불완전함과 교회 내부의 잘못을 인정한다.
- 설명 뒤에는 관련 페이지와 다음 질문으로 이동할 수 있게 한다.

### 파주꽃동산교회 적용 원리

파주꽃동산교회는 다음과 같은 별도 콘텐츠 구조를 가질 수 있다.

- `교회가 처음이라면`: 교회가 무엇을 하는지 쉬운 말로 설명
- `예수님과 말씀`: 성경과 설교를 통해 예수님을 어떻게 전하는지 설명
- `예배가 궁금하다면`: 실제 예배 순서와 방문 안내
- `질문이 있다면`: 공개 가능한 질문과 문의 경로

설명은 최철민 목사의 신학을 새로 창작하는 방식이 아니라, 실제 설교와 성경과 교회의 공식 자료를 연결하는 방식이어야 한다. 헌법에 따라 성경, 실제 설교, 실제 목회와 삶이 AI 해석보다 우선한다.

## 4. 예수님을 소개하는 방식

`예수님` 페이지는 예수님을 추상적인 교리 문장 하나로 끝내지 않는다.

### 확인된 구성

1. 예수님이 기독교의 중심이라는 선언
2. 역사적 설명과 신앙고백의 구분
3. 탄생·성장, 가르침·사역, 십자가, 부활, 제자들의 사명
4. 하나님 사랑, 이웃 사랑, 회개와 용서, 겸손과 섬김, 원수 사랑, 하나님 나라
5. 십자가와 부활이 왜 중요한지 별도 설명
6. 마가복음·누가복음·요한복음으로 직접 읽는 방법

### 추출할 원리

- 예수님을 “믿어야 하는 대상”으로만 시작하지 않고, 삶과 행동과 가르침을 먼저 보여준다.
- 사실 설명과 신앙고백을 섞지 않아 신뢰를 만든다.
- 십자가와 부활을 각각 설명하여 핵심 복음의 논리를 단계적으로 이해하게 한다.
- 독자가 직접 성경을 읽어 볼 수 있는 구체적인 다음 행동을 제시한다.

### 파주꽃동산교회 적용 시 주의

파주꽃동산교회는 이 구조를 그대로 복제하지 않는다. 실제 최철민 목사의 설교에서 예수님과 복음을 어떻게 전했는지 확인한 뒤, 실제 설교 원문·영상·성경 본문으로 연결해야 한다. 확인되지 않은 표현을 목사님의 메시지처럼 만들지 않는다.

## 5. 교회 방문에 대한 심리적 장벽을 낮추는 방식

이 사이트가 가장 구체적으로 다루는 영역이다. 방문자가 느끼는 막연한 불안을 실제 상황 단위로 쪼개서 답한다.

### 다루는 장벽

- 복장
- 성경책과 찬송가 준비
- 헌금 의무
- 새가족 등록 압박
- 혼자 방문하는 상황
- 예배 중 행동을 모르는 문제
- 아이 동반, 장애인 접근, 통역 등 사전 문의
- 주차와 교통
- 예배 후 어떻게 행동할지

### 장벽 완화 문장의 구조

1. 방문자가 느낄 수 있는 불안을 먼저 인정한다.
2. 특별한 지식이나 준비가 필요하지 않다고 알려 준다.
3. 무엇을 해도 되는지보다 하지 않아도 되는 것을 명확히 말한다.
4. 방문자가 선택권을 가지고 있음을 반복한다.
5. 방문 후에도 즉시 결정하지 않아도 된다고 안내한다.

### 파주꽃동산교회 적용 원리

현재 정보 문서에 있는 실제 예배 시간, 예배 장소, 주차 주소, 주차비 지원, 연락처를 활용해 다음 콘텐츠를 구성할 수 있다.

- `처음 오시는 분께`
- `예배 전에 확인할 것`
- `주차와 입장`
- `예배 중 모르는 순서가 있어도 괜찮습니다`
- `예배 후 바로 돌아가도 괜찮습니다`
- `문의하고 싶은 것이 있다면`

단, 참조 사이트의 “건강한 교회 점검” 항목을 파주꽃동산교회의 사실이나 자기평가처럼 복사해서는 안 된다. 파주꽃동산교회에는 실제로 확인 가능한 운영·예배·문의 정보를 중심으로 적용한다.

## 6. FAQ 구성

### 관찰된 FAQ IA

FAQ는 한 페이지 안에서 다음 네 그룹으로 나뉜다.

1. 기독교에 관한 질문
2. 성경에 관한 질문
3. 교회에 관한 질문
4. 생활에 관한 질문

질문 예시는 추상적 교리만이 아니라 다음과 같이 실제 불안과 오해를 포함한다.

- 하나님이 실제로 존재하는가
- 구원과 믿음은 무엇인가
- 성경은 어떤 책이며 어디부터 읽는가
- 교단이 왜 여러 개인가
- 교회에 다녀야만 기독교인인가
- 헌금은 왜 하는가
- 교회에서 상처를 받았다면 어떻게 하는가
- 다른 종교를 가진 사람을 어떻게 대하는가

FAQ 답변은 입문자용 요약임을 밝히고, 신학적 견해가 갈리는 주제에는 차이가 있을 수 있다고 표시한다.

### UI 패턴

- 질문을 세로 목록으로 배치
- 질문 버튼을 누르면 답변이 펼쳐지는 Accordion
- `aria-expanded` 상태로 열림 여부를 표시
- 열린 항목의 `+` 아이콘이 회전
- FAQ 전체 페이지와 관련 페이지 사이에 이전·다음 연결
- 답변이 충분하지 않을 때 익명 질문 게시판으로 이동

### 파주꽃동산교회 적용 원리

기존 홈페이지 FAQ는 교회 내부 행정 질문만 모으지 말고, 첫 방문자 중심 질문과 신앙 질문을 나누는 것이 적절하다.

권장 그룹:

- 처음 교회에 오는 분
- 예배와 방문 정보
- 예수님과 말씀
- 어린이·가정·다음세대
- 지역사회 사역
- 문의와 개인정보

실제 답변이 없는 질문은 만들지 말고, `문의하기` 또는 `준비 중`으로 남긴다.

### Hero

- 짧은 eyebrow 문장
- 질문형 또는 허용형 큰 제목
- 설명 문장
- 두 개의 CTA: 핵심 설명과 방문 준비
- 장식보다 사용자의 다음 선택을 돕는 보조 시각 요소

### Cards

- 번호가 있는 질문 선택 카드
- 카드 전체가 링크인 구조
- 짧은 설명과 텍스트 링크를 함께 제공
- 호버·포커스 시 이동 가능하다는 피드백

### Page Hero

- 내부 페이지마다 현재 위치를 알 수 있는 짧은 라벨
- 제목과 설명을 한 덩어리로 제공
- 홈으로 돌아가는 경로와 다음 콘텐츠 연결

### FAQ

- 버튼 기반 Accordion
- 키보드 포커스 스타일
- `aria-expanded` 상태
- 질문이 길어도 답변을 숨겨 처음 화면을 과밀하게 만들지 않음

### Forms / Questions

- 익명 질문을 위한 최소 입력
- 이름·이메일을 받지 않는다는 안내
- 글자 수 표시
- 등록 후 익명 표시

파주꽃동산교회에 즉시 적용할 UI는 Navigation, Hero, 질문 선택 카드, FAQ Accordion, 페이지 간 이전·다음 연결이다. 익명 게시판은 실제 운영 주체와 저장·관리 방식이 정해진 뒤 별도로 판단한다.

## 9. 파주꽃동산교회에 적용할 수 있는 콘텐츠 구조

현재 파주꽃동산교회 Brief와 헌법을 기준으로 다음과 같이 재구성할 수 있다.

### A. 첫 방문 진입

Hero 아래에 다음 선택지를 둔다.

- 교회가 처음이라면
- 예수님과 말씀을 알고 싶다면
- 이번 주 예배에 오고 싶다면
- 아이와 함께 방문하려면

### B. 교회 소개의 순서

기존 교회 홈페이지처럼 교단·연혁·조직을 먼저 길게 설명하기보다 다음 순서가 적절하다.

1. 파주꽃동산교회가 지금 누구를 환대하는가
2. 예수님과 말씀이 교회의 중심이라는 사실
3. 현재의 예배와 공동체
4. 최철민 목사의 실제 설교와 목회 방향
5. 아이들·가정·지역사회에서 이어지는 실제 만남
6. 공식 예배·문의 정보

### C. 말씀·예수님 콘텐츠

- `예수님과 말씀` 소개 페이지
- 175편 설교 아카이브에서 실제 원본으로 이동
- 설교를 주제별로 연결하되, 분류가 설교 원문을 대체하지 않게 함
- 비신자에게는 삶의 질문에서 시작해 말씀으로 연결
- 기존 성도에게는 본문·설교·적용 자료로 깊어지는 경로 제공

### D. 첫 방문 안내

- 현재 주일예배: 오후 3시 30분
- 현재 예배 장소: 경기 파주시 미래로602번길 27 태운플라자 7층
- 주차 장소: 경기 파주시 미래로602번길 11 건물 지하주차장
- 주차비: 교회 지원
- 문의: 현재 공식 연락처

위 정보는 `CHURCH_CURRENT_INFO.md`를 기준으로 사용하고, 과거 자료의 주소·시간을 우선하지 않는다.

### E. 지역사회·다음세대

지역아동센터와 어린이 축구교실을 단순 프로그램 카드로만 보여주지 않고 다음 질문으로 연결한다.

- 누구를 만나고 있는가
- 어떤 돌봄과 희망을 나누는가
- 현재 공개 가능한 실제 기록은 무엇인가
- 방문자나 지역 주민이 다음에 무엇을 알거나 문의할 수 있는가

실제 사진·영상이 없을 때는 비사실적 임시 이미지임을 분명히 하고, 현장 기록을 대체하지 않는다.

## 10. 적용하면 안 되거나 그대로 복제하면 안 되는 부분

### 그대로 복제하면 안 되는 것

- `한걸음`이라는 브랜드명, 로고, 색상, 문구
- “처음 만나는 기독교와 교회”라는 사이트의 독립적 포지셔닝
- 페이지 제목과 설명 문장
- Hero의 장식 그래픽, 카드 비주얼, 아이콘 도형
- 하단 고정 메뉴의 동일한 항목과 순서
- FAQ 질문과 답변 문장
- 익명 질문 게시판의 운영 방식과 외부 저장 구조
- 영어·한국어 사이트 구조를 필요 검토 없이 그대로 가져오는 것

### 파주꽃동산교회에 그대로 적용하면 안 되는 정보 구조

- 파주꽃동산교회를 일반적인 기독교 입문 사이트로만 만드는 것
- 최철민 목사와 실제 교회 사역을 부록처럼 뒤로 미루는 것
- 예수님 설명이 실제 파주꽃동산교회의 설교·말씀과 분리되는 것
- 익명 질문 기능을 운영 책임·개인정보 기준 없이 먼저 도입하는 것
- 교회 방문자의 불안을 다룬다는 이유로 파주꽃동산교회가 스스로 “건강한 교회”라고 선언하는 것
- 교단·신앙고백·역사 등 확인되지 않은 내용을 일반화하는 것

### 참고할 수 있지만 재구성이 필요한 것

- 질문 중심 Hero
- 첫 방문자의 금지·불안·준비물에 답하는 콘텐츠
- 기독교 기본 설명의 단계화
- 예수님의 삶·가르침·십자가·부활을 나누는 구조
- FAQ를 주제별로 묶는 방식
- 각 페이지의 이전·다음 콘텐츠 연결
- 질문에서 작은 다음 행동으로 이어지는 CTA

## 결론

이 Reference의 가장 중요한 기여는 시각 스타일이 아니라 **교회를 모르는 사람의 질문을 출발점으로 삼는 정보 설계**다.

파주꽃동산교회에는 다음 세 가지 원리를 우선 가져오는 것이 적절하다.

1. **처음 방문자용 질문 진입점**을 공식 홈페이지 안에 둔다.
2. **예수님과 말씀을 쉬운 설명에서 실제 설교·예배로 연결**한다.
3. **방문 불안을 실제 정보와 선택권으로 낮추고**, 예배 안내·문의·다음 콘텐츠로 자연스럽게 이어지게 한다.

반대로 파주꽃동산교회의 중심은 실제 최철민 목사의 설교와 목회, 현재 예배, 지역사회와 다음세대 사역이다. 따라서 `한걸음`의 입문자 UX를 보조 구조로 활용하되, 최종 사이트의 정체성과 콘텐츠는 파주꽃동산교회의 확인된 자료에서 구성해야 한다.
