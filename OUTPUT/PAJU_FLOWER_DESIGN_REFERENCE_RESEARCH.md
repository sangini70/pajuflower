# 파주꽃동산교회 웹사이트 디자인 레퍼런스 조사

조사일: 2026-09-22
Source: [Land-book](https://land-book.com/)

## 프로젝트 기준

현재 프로젝트 헌법 v1에서 확인한 기준은 다음과 같다.

- 규모를 먼저 보여주는 교회가 아니라 사람 곁에 있는 교회
- 예수 그리스도와 말씀을 중심에 두고, 웹사이트는 전달을 돕는 수단으로 사용
- 아이들, 가정, 교회를 떠난 사람, 삶에 지친 사람, 지역사회와 연결
- 과거 미화·공격·변명보다 현재의 예배, 섬김, 말씀, 앞으로의 사명을 기록
- 교회를 처음 접하는 사람도 부담 없이 이해할 수 있는 삶의 언어 사용

## 선정한 전체 사이트 레퍼런스

### 1. Churchy — Church Webflow Template

URL: https://land-book.com/websites/21030-churchy-church-html5-responsive-website-template

참고할 점:

- 교회 사이트에 필요한 예배, 행사, 소그룹 정보를 한 사이트 안에서 구조화하는 방향
- 밝은 톤과 명확한 정보 위계
- 교회 방문 전 필요한 정보를 빠르게 찾게 하는 탐색 구조

적용 범위:

- 예배 안내, 설교, 행사, 공동체 섹션의 정보 구조만 참고한다.
- 템플릿의 시각 디자인과 문구를 복제하지 않는다.

### 2. Global Wildlife Rescue and Conservation Centre in Jamnagar | Vantara

URL: https://land-book.com/websites/94993-global-wildlife-rescue-and-conservation-centre-in-jamnagar-vantara

참고할 점:

- Hero에서 기관의 사명과 정서적 이미지를 먼저 연결하는 방식
- About, 핵심 활동, 리소스, 후기, CTA, Footer로 이어지는 긴 호흡의 정보 흐름
- 사진·영상과 카드형 콘텐츠를 사용해 활동을 추상적 주장보다 실제 장면으로 보여주는 방식

적용 범위:

- 교회의 사명을 선언으로만 두지 않고 예배, 지역 섬김, 아이들 사역의 실제 장면으로 연결한다.
- 동물보호기관의 이미지나 표현을 교회 콘텐츠에 그대로 가져오지 않는다.

### 3. The Australian Literacy and Numeracy Foundation | ALNF

URL: https://land-book.com/websites/74916-the-australian-literacy-and-numeracy-foundation-alnf

참고할 점:

- 사람과 공동체를 중심에 둔 이미지 사용

- 배경 영상과 큰 Footer를 사용하되, 본문 정보는 단순하게 유지하는 방식

적용 범위:

- 아이들·가정·지역사회 섹션에서 실제 사람의 표정과 관계가 드러나는 사진을 우선한다.
- 큰 제목은 교회 내부 용어보다 삶의 질문과 환대의 언어에 사용한다.

### 4. Hempel Foundation — Accelerating Change Together

URL: https://land-book.com/websites/82622-hempel-foundation-accelerating-change-together-hempel-foundation

참고할 점:

- 하나의 큰 목적을 여러 활동과 사례로 나누어 보여주는 구조

적용 범위:

- 기업·재단식 성과지표나 과도한 숫자 중심 표현은 사용하지 않는다.

### 5. Welcome to the Obama Foundation

URL: https://land-book.com/websites/76685-welcome-to-the-obama-foundation

참고할 점:

- 기관의 사람 중심 서사를 큰 이미지와 짧은 문장으로 진입시키는 방식
- 활동 소개와 참여 유도 사이의 명확한 정보 계층
- 사진과 텍스트의 리듬을 교차시켜 긴 페이지를 읽게 하는 방식

적용 범위:

- 목사 소개는 개인을 영웅화하기보다 말씀, 삶, 지역 섬김의 관계를 보여주는 구조로 재구성한다.
- 참여 CTA는 후원 중심으로 가정하지 않고 예배, 말씀, 문의, 지역 섬김 참여 등 실제 접점에 맞춘다.

## 추출한 공통 디자인 원칙

1. **Warm and human**: 건물이나 규모보다 사람의 표정, 손길, 관계가 먼저 보이게 한다.
2. **Quiet confidence**: 따뜻한 아이보리·차분한 녹색·짙은 잉크색을 기본으로 하고, 포인트 색은 절제한다.
3. **Clear hierarchy**: 한 화면에 하나의 핵심 메시지만 두고, 모바일에서는 섹션 수와 문장 길이를 줄인다.
4. **Real media first**: 실제 예배·설교·지역 섬김 사진과 영상을 우선 사용하며, 생성 이미지로 실제 활동을 대체하지 않는다.
5. **Invitation over pressure**: 방문자에게 결정을 강요하기보다 예배, 말씀, 문의로 이어지는 낮은 문턱의 CTA를 사용한다.
6. **Story-led structure**: 교회 소개 → 말씀과 설교 → 사람을 만나는 사역 → 예배와 연결 → 문의의 흐름을 만든다.
7. **Reference is analysis, not cloning**: 선정 사례의 레이아웃 원리만 추출하고 색상·문구·사진·브랜드 표현은 파주꽃동산교회 고유 자료로 재구성한다.

## 현재 단계의 제한

- 별도 웹사이트 Brief, 실제 교회 사진, 목사님 Reference Image, 예배 정보 원문은 아직 확인되지 않았다.
- 따라서 이 문서는 디자인 방향과 레퍼런스 분석 기록이며, 실제 웹 구현안이나 이미지 생성 프롬프트가 아니다.
- 실제 Hero·Profile·Gallery 설계 전에는 해당 콘텐츠와 `1_model_image/`의 실제 자산을 먼저 확인한다.
